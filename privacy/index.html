개인정보처리방침

시행일 2026년 8월 10일 · 최종 수정 2026년 8월 10일

Mindora(이하 “서비스”)는 회원가입을 받지 않습니다. 학습 기록은 기본적으로 이용자의 브라우저 안에만 저장되며, 서버로 나가는 기능은 이용자가 항목별로 켰을 때만 동작합니다. 이 문서는 무엇이 기기에 남고, 무엇이 동의했을 때만 서버로 가며, 어떻게 지울 수 있는지를 실제 동작 그대로 적은 것입니다.

세 줄 요약

① 회원가입·로그인이 없고 이름·연락처를 받지 않습니다. ② 학습 기록·프로필·계획표·등록한 음악은 이 브라우저 저장소에만 남고 서버로 가지 않습니다. ③ 학교 리그·학급 대항전·포스트잇·관리자 공개는 각각 따로 켜야 동작하며, 언제든 끄면 즉시 중단되고 서버 기록 삭제를 요청합니다.

1. 이 브라우저에만 저장되는 정보

아래 항목은 이용자의 기기(브라우저 localStorage · IndexedDB)에만 저장됩니다. 서비스 운영자는 이 값을 볼 수 없고, 어떤 서버로도 전송되지 않습니다.

  • 프로필 — 이름(별명), 학교명, 학교급, 학년, 반, 주간 목표 시간
  • 오늘의 상태 입력 — 수면 시간·질·규칙성, 스트레스, 피로도, 기분, 식사·수분·카페인·운동, 학습 시각
  • 학습 준비도 참고값과 그 이력 (최근 180일)
  • 순공 시간 기록 — 날짜별·과목별 분
  • 공부 후 피드백 · 시험 회고 · 개인 학습 실험 응답
  • 목표 대학·다짐·D-day, 방학 계획표, 모리(캐릭터) 성장, 배지·경험치, 사운드 설정, 식사 알리미 시각
  • 직접 등록한 음악 파일 — IndexedDB 에 저장되며 전송되지 않습니다
  • 나이스 API 인증키 — 개인 자격 증명이므로 백업 파일에도 포함하지 않습니다

브라우저 데이터를 지우거나 기기를 바꾸면 위 기록은 함께 사라집니다. 서비스는 이를 복구할 수 없으므로 설정 화면의 백업 파일 내려받기를 권합니다.

2. 동의했을 때만 서버로 전송되는 정보

아래 기능은 기본값이 모두 꺼짐이며, 설정에서 각각 따로 켜야 동작합니다. 하나를 켜도 나머지는 켜지지 않습니다.

기능전송되는 항목목적
학교 리그 학교명, 주차, 주간 순공 시간, 무작위 기기 번호(UUID), 랭킹 숨김 여부 학교별 주간 순공 시간 합계 비교
학급 대항전 위 항목 + 학교급, 학년, 반, 닉네임 같은 학교·학년·반 단위 순위표 구성
우리 반 포스트잇 위 항목 + 쪽지 내용, 색, 화면상 위치 같은 반 학생 간 짧은 메시지 공유
관리자에게 내 기록 보이기 닉네임, 학교명, 주차, 주간 순공 시간, 무작위 기기 번호 학교 관리자(교사)의 학습 현황 확인

전송하지 않는 것: 과목명, 시험 일정, 수면·스트레스·피로·기분 등 상태 입력, 학습 준비도 참고값, 공부 후 피드백, 계획표, 등록한 음악은 위 기능을 모두 켜도 서버로 가지 않습니다.

닉네임은 순위표에 그대로 표시되므로 실명 사용을 권하지 않습니다. 같은 반에서 5명 이상이 참여해야 개별 순위가 다른 학생에게 공개되며, 내 랭킹 숨기기를 켜면 반 합계에는 포함되되 개별 줄은 보이지 않습니다.

3. 보관 기간과 파기

  • 기기 안의 기록 — 이용자가 지울 때까지. 학습 준비도 이력은 최근 180일만 유지하고 오래된 것부터 자동으로 지웁니다.
  • 리그·관리자 공개 기록 — 서버에서 60일이 지난 주차 기록을 정기적으로 삭제합니다.
  • 포스트잇 — 작성 시 고른 수명(10 · 15 · 20 · 30분)이 지나면 서버에서 삭제됩니다.
  • 동의를 끄면 새 전송이 즉시 중단되고, 그 기기가 올린 서버 기록의 삭제를 요청합니다. 연결 문제로 실패하면 기기에 요청을 보관해 두었다가 다음 실행 때 다시 시도합니다.

나이스 조회는 이용자가 학교를 검색하거나 급식·학사일정을 볼 때만 발생하며, 이름·닉네임·학습 기록은 포함되지 않습니다. 위 사업자에 대한 이용을 원하지 않으면 해당 기능을 쓰지 않으면 됩니다 — 온라인 기능을 모두 꺼도 분석·플랜·타이머·계획표·로컬 기록은 그대로 동작합니다.

5. 쿠키와 유사 기술

서비스는 광고·분석 목적의 쿠키를 심지 않습니다. 다만 아래 브라우저 저장소를 기능 목적으로 사용합니다.

  • localStorage — 1항의 학습 기록 전부, 그리고 각 공유 기능의 동의 여부
  • sessionStorage — 소개 페이지를 거쳐 앱으로 들어왔는지 표시 (탭을 닫으면 사라짐)
  • IndexedDB — 이용자가 등록한 음악 파일
  • Cache Storage — 오프라인 실행을 위한 앱 화면 사본 (서비스 워커)

6. 만 14세 미만 이용자

서비스는 초·중학생도 이용 대상으로 하며, 학교급을 초등학교·중학교로 고르면 성장 모드가 켜집니다. 회원가입과 연락처 수집이 없어 기본 이용에는 개인정보 제공이 필요하지 않습니다. 다만 2항의 서버 전송 기능(학교 리그·학급 대항전·포스트잇·관리자 공개)은 닉네임과 학교·학년·반이 함께 전송되므로, 만 14세 미만 이용자는 보호자와 함께 켤지 결정하시기 바랍니다. 보호자는 아래 연락처로 해당 기록의 삭제를 요청할 수 있습니다.

7. 이용자의 권리와 행사 방법

  • 열람·내려받기 — 설정 → 데이터 관리 → 백업 파일 내려받기로 기기에 저장된 전부를 JSON 으로 받을 수 있습니다.
  • 삭제 — 같은 화면의 모든 기록 삭제로 기기의 기록을 즉시 지웁니다.
  • 동의 철회 — 각 공유 기능의 스위치를 끄면 전송이 중단되고 서버 기록 삭제가 요청됩니다. 철회 완료 여부는 각 설정 아래에서 확인할 수 있습니다.
  • 그 밖의 요청 — 위 방법으로 해결되지 않으면 아래 연락처로 문의해 주세요.

8. 안전성 확보 조치

  • 모든 통신은 HTTPS 로 암호화합니다.
  • 서버 데이터는 행 수준 보안(RLS)으로 접근을 제한하며, 학생 개별 기록은 별도로 만든 관리자 계정으로만 조회됩니다.
  • 기기를 식별하는 값은 이름이나 연락처가 아니라 무작위로 생성한 번호(UUID)이며, 이 값만으로는 개인을 특정할 수 없습니다.
  • 포스트잇 내용은 게시 전과 표시 시점 양쪽에서 욕설·비하 표현을 걸러 냅니다.

9. 광고

현재 서비스에는 광고가 게재되어 있지 않습니다. 향후 Google AdSense 등 광고를 도입하는 경우, 광고 사업자가 쿠키를 사용해 맞춤 광고를 제공할 수 있으며 그 시점에 이 방침을 먼저 갱신하고 아래 시행일을 바꿔 안내하겠습니다.
