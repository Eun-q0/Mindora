    🏫

    나이스(NEIS) 연동

    교육정보 개방포털 API 키를 넣으면 실제 학교 검색과 급식 식단을 불러옵니다. 키를 비우면 연동을 끄고 오프라인 자동완성만 씁니다. 키는 open.neis.go.kr 에서 무료로 발급받습니다.

    🔒 키는 소스 코드에 포함되지 않고 이 브라우저의 저장소에만 남습니다. 다른 기기나 브라우저에서 쓰려면 그곳에서 한 번 더 입력하면 됩니다.

    🗄️

    데이터 관리

    모든 데이터는 이 브라우저에만 저장됩니다. 브라우저 데이터를 지우거나 기기를 바꾸면 그대로 사라집니다. 가끔 백업 파일로 내려받아 두세요.

    백업에는 프로필·학습 기록·뇌 컨디션·그룹·배지·사운드 설정이 담깁니다. 나이스 인증키는 개인 자격 증명이라 백업에 포함하지 않습니다. 새 기기에서는 설정에서 한 번 더 입력하세요.
