# 🧠 Mindora — 오늘의 학습 준비도 코치

사용자가 직접 입력한 수면·스트레스·피로·기분을 바탕으로 **오늘 어떤 종류의 공부부터 시작하면 부담이 적을지** 참고값을 보여 주고,
**최소·확장 목표 → 과목별 시간 배분 → 타이머 → 공부 후 5초 피드백 → 개인별 경향**까지 이어지는 학습 앱입니다.

표시값은 능력·지능이나 의학적 상태를 측정한 결과가 아닙니다. 자기보고 입력을 규칙 기반 모델 v1로 계산한 학습 계획용 추정치이며, 화면에서는 5점 단위와 구간으로 표시합니다.

---

## 실행 방법

`index.html` 을 더블클릭하세요. 설치가 필요 없습니다.

학습 기록·프로필·과목·시험·수면·스트레스·학습 준비도·공부 후 피드백은 기본적으로 이 브라우저에 저장됩니다.
인터넷 연결은 나이스 학교 정보와 사용자가 동의한 학교 리그·학급 대항전·관리자 공개에만 사용합니다.
온라인 기능을 모두 꺼도 분석·플랜·타이머·계획표·로컬 기록은 그대로 동작합니다.

### 🔒 온라인 기능과 전송 범위

| 기능 | 켰을 때 전송되는 정보 | 기본값 |
|---|---|---|
| 나이스 학교 정보 | 학교 검색어·학교 코드·조회 날짜, 시간표 조회 시 학년·반 | 필요할 때만 조회 |
| 학교 리그 | 학교명·주차·주간 순공 시간·무작위 기기 번호·랭킹 숨김 여부 | 꺼짐 |
| 학급 대항전 | 학교 리그 항목 + 학교급·학년·반·닉네임 | 꺼짐 |
| 관리자 공개 | 닉네임·학교명·주차·주간 순공 시간·무작위 기기 번호 | 꺼짐 |

과목·시험 일정·수면·스트레스·학습 준비도 참고값은 위 온라인 기능으로 전송하지 않습니다.
학교 리그와 관리자 공개는 서로 별개의 동의이며 설정에서 각각 끌 수 있습니다.

### 🔑 학교 검색 · 급식을 쓰려면 (선택)

인증키 없이도 실제 학교 검색·급식·시간표 조회가 됩니다. 다만 키 없는 요청은 검색 결과가 최대 5건이라
흔한 학교 이름은 원하는 결과가 잘릴 수 있습니다. 무료 인증키를 넣으면 한 번에 최대 30건을 받아 더 정확하게 찾습니다.

1. [open.neis.go.kr](https://open.neis.go.kr) 에서 인증키를 무료로 발급받습니다.
2. 앱을 열고 **설정 → 나이스(NEIS) 연동 → API 인증키** 에 붙여넣습니다.
3. `연결 확인` 을 눌러 정상인지 확인합니다.

키는 그 브라우저의 localStorage 에만 저장되며 저장소에 커밋되지 않습니다.
키를 넣지 않아도 나이스 조회와 나머지 기능은 동작합니다.

## 화면 구성

**한 번에 한 페이지만 보입니다.** 길게 스크롤하지 않아도 되도록 상단 탭으로 전환합니다.

| 탭 | 내용 |
|---|---|
| 오늘 | 오늘 상태, 첫 추천, 학습시간, 시험 일정을 한눈에 확인 |
| 1 입력 | 핵심 컨디션 5개와 과목, 선택 상세 입력 |
| 2 컨디션 분석 | 5가지 과제 적합도 참고값과 주요 이유 |
| 3 학습 플랜 | 최소·확장 목표, 추천 수정, 타임라인, 휴식 가이드 |
| 4 타이머 | 뽀모도로 + 순공 시간 + 집중 사운드 재생 |
| ★ 내 성장 | 초·중학생 전용 (경험치·배지·미션) |
| 계획표 | 방학 계획표 자동 배분·편집·이미지 저장 |
| 랭킹 | 같은 반 순공 시간 등수 |
| 리그 | 반 대항·학교 대항 주간 리그 |
| 리포트 | 주간 기록, 7일 이후 개인 경향, 목표 제안, 시험 회고, 개인 실험 |
| ⚙ 설정 | 프로필·사운드·나이스 연동·데이터를 한곳에서 관리 |
| 🎨 캐릭터 꾸미기 | 프로필 캐릭터·테두리 (설정 → 내 프로필에서 들어갑니다) |

- 아직 분석하지 않았으면 2·3·4번 탭은 나타나지 않습니다. 분석을 마치면 자동으로 열립니다.
- 페이지 아래에 **← 이전 / 다음 →** 버튼이 있어 순서대로 따라가기 쉽습니다.
- 주소창 해시로도 이동합니다 (`#timer`, `#settings`, `#report` …). 브라우저 뒤로가기도 동작합니다.
- **설정은 ⚙ 탭 한곳에 모여 있습니다** — 프로필·그룹, 알림음, 사운드 자동 재생, 과목별 사운드,
  내 음악 등록, 데이터 삭제. 타이머 화면의 `설정 →` 버튼으로도 바로 갈 수 있습니다.

## 사용 흐름

### 00. 시작하기 — 프로필과 그룹

처음 열면 프로필 입력 화면이 먼저 나옵니다. **이름·학교명·학교급·학년**(선택: 반, 주간 목표 시간)을 넣으면
`학교 + 학교급 + 학년 (+반)` 조합으로 **스터디 그룹**이 만들어집니다.
예: `한빛고등학교 2학년 3반`. 반을 비우면 학년 전체가 한 그룹이 됩니다.

**학교명은 전체를 다 칠 필요가 없습니다.** 두 글자만 입력하면 아래에 후보가 뜹니다.

- 🏫 **나이스 검색** — `경기고` 를 치면 실제 학교 목록에서 `경기고등학교 (서울특별시 · 고등학교)` 를 찾아 줍니다.
  목록에서 고르면 **학교급도 자동으로 맞춰지고, 급식 조회에 필요한 학교 코드가 함께 저장**됩니다.
- 🕘 전에 입력했던 학교와 그룹원들의 학교도 함께 뜹니다
- 인터넷이나 API 키가 없으면 오프라인 완성으로 대체됩니다
  (`한빛` + `고등학교` → 한빛고등학교 / `초`·`중`·`고`·`여고`·`여중` 축약 인식)
- 방향키 ↑↓ 로 고르고 Enter 로 선택, Esc 로 닫기

### 🍱 오늘의 급식

프로필에서 **학교를 검색해 목록에서 선택**하면, 입력 화면의 `식사 · 영양` 카드에 오늘 급식이 나옵니다.

- 조식 / 중식 / 석식별로 메뉴와 칼로리
- 반찬마다 알레르기 유발 번호를 표시하고, 카드 아래에 이름으로 풀어 줍니다
  (예: `알레르기 유발 — 1 난류 · 2 우유 · 5 대두 · 6 밀 · 9 새우 · 13 아황산류`)
- 급식이 있는데 그 끼니를 체크하지 않았으면 알려 줍니다 → 영양 점수 입력이 정확해집니다
- 주말·방학이라 급식이 없으면 그렇게 안내합니다
- 같은 날 같은 학교 조회는 6시간 동안 캐시해 API 호출을 아낍니다

> 학교 이름을 직접 타이핑만 하고 목록에서 고르지 않으면 급식이 나오지 않습니다.
> 같은 이름의 학교가 여러 지역에 있어 이름만으로는 특정할 수 없기 때문입니다.

### 01. 데이터 입력

| 분류 | 항목 |
|---|---|
| 수면 | 수면 시간, 수면의 질(1~5), 수면 규칙성(1~5) |
| 심리·신체 | 스트레스(0~10), 피로도(0~10), 기분(1~5) |
| 선택 상세 | 식사·수분·카페인·운동·학습 시각·가용 시간 |
| 과목 | 과목명, 유형, 시험일, 중요도(1~5), 준비도(1~5) — 최대 8개 |

처음에는 수면 시간·스트레스·피로도·기분·과목만 입력해도 됩니다. 나머지는 `선택 입력 · 평소 설정`에서 필요할 때만 펼칩니다.

### 02. 오늘의 학습 컨디션 분석

| 참고값 | 주로 참고하는 자기보고 입력 | 용도 |
|---|---|---|
| 🎯 **집중 과제 적합도** | 수면 시간, 피로도, 스트레스 | 긴 집중 블록의 부담 조절 |
| 🧠 **기억 과제 적합도** | 수면 시간, 수면의 질 | 암기·복습 과제 순서 참고 |
| 🔢 **계산 과제 적합도** | 피로도, 수면, 식사 | 계산형 과제 순서 참고 |
| 💡 **창의 과제 적합도** | 기분, 스트레스 | 서술·발상 과제 순서 참고 |
| 📖 **독해 과제 적합도** | 수면 시간, 피로도 | 읽기·이해 과제 순서 참고 |

화면은 지나친 정밀함을 피하려고 5점 단위 참고값과 `높음·보통·낮음` 같은 구간을 함께 보여 줍니다. 세부 설명도 입력 범위와 방향만 안내하며, 인과관계나 개인의 고정된 능력처럼 표현하지 않습니다.

### 03. 학습 플랜

```
우선순위 = 0.34 × 긴급도(시험 D-day)
         + 0.24 × 준비도 격차
         + 0.24 × 중요도
         + 0.18 × 오늘의 과제 적합도
```

- 블록을 배치할 때 시간대별 참고값을 반영하되, 사용자의 최근 추천 피드백을 우선 참고합니다.
- 같은 과목을 연달아 붙이지 않습니다(**인터리빙**).
- 컨디션에 따라 학습법 자체가 달라집니다. (계산 과제 적합도가 낮게 나온 날엔 "실전 세트" 대신 "오답노트·풀이 과정 재현")
- 추천 카드에서 `과목 바꾸기`, `시간 줄이기`, `오늘 제외`, `이 추천이 맞지 않음`을 선택할 수 있습니다.
- 첫 블록을 **오늘의 최소 목표**, 여유가 있을 때 할 다음 블록을 **확장 목표**로 구분합니다.

### 04. 뽀모도로 타이머 + 순공 시간 측정

종합 컨디션에 따라 집중/휴식 길이가 자동 결정됩니다.

| 종합 점수 | 모드 | 집중 / 휴식 |
|---|---|---|
| 85+ | 딥워크 | 50분 / 10분 |
| 74~85 | 집중 강화 | 45분 / 9분 |
| 62~74 | 표준 플러스 | 35분 / 7분 |
| 50~62 | 클래식 뽀모도로 | 25분 / 5분 |
| 38~50 | 저부하 | 20분 / 8분 |
| ~38 | 회복 우선 | 15분 / 10분 |

**순공(순수 공부) 시간**은 타이머가 "집중" 상태로 실제 흐른 시간만 과목별로 누적됩니다.
일시정지·휴식·건너뛴 시간은 쌓이지 않습니다. 20초마다 중간 저장되고, 탭을 닫거나 숨길 때도 저장됩니다.

집중 블록이 끝나면 약 5초 안에 집중 체감·난이도·추천 적합도를 남길 수 있습니다. 응답은 다음 추천의 과목별 가중치에 반영되며, 건너뛰어도 타이머 기록은 유지됩니다.

### 05. 개인화와 다시 쓰게 만드는 기능

- **개인 학습 패턴:** 실제 학습일 7일 이상, 비교 구간별 2일 이상일 때만 `기록에서 나타난 경향`으로 보여 줍니다. 인과관계로 단정하지 않습니다.
- **주간 목표 자동 조정:** 완료된 최근 2~3주 평균에서 약 10% 높게 제안하고, 한 번에 최대 15%까지만 올립니다.
- **시험 후 회고:** 종료된 시험의 기록 시간과 실제 결과 체감을 연결해 다음 계획의 참고 데이터로 저장합니다.
- **개인 학습 실험:** 물, 집중 블록 길이, 음악, 산책 등의 조건을 6일간 비교합니다. 결과는 집중 체감의 차이이며 과학적 인과 검증으로 표현하지 않습니다.

### 🎧 집중 사운드 — 과목과 상태에 맞춰 자동으로

타이머 화면에 있습니다. 집중 블록이 시작되면 자동으로 재생되고, 일시정지·휴식 때는 멈춥니다.

**모든 소리는 Web Audio API 로 그 자리에서 합성합니다.** 음원 파일을 담고 있지 않아서 인터넷 없이 돌아가고,
저작권 있는 음원을 배포하지도 않습니다.

| 종류 | 트랙 |
|---|---|
| 노이즈 | ⚪ 백색소음 · 🌸 핑크노이즈 · 🟤 브라운노이즈 |
| 환경음 | 🌧️ 빗소리 · 🌊 파도 · ☕ 카페 소음 · 🔥 모닥불 |
| 연주 | 🎷 재즈 무드 · 🎧 로파이 비트 · 🌌 딥 드론 |

재즈 무드는 ii-V-I-VI 코드 진행에 워킹 베이스와 브러시 드럼을 실시간으로 연주합니다.
로파이 비트는 킥·스네어·하이햇과 따뜻한 화음, 바이닐 잡음을 함께 만듭니다. 녹음이 아니라 연주입니다.

#### 과목 유형별 기본 설정 (직접 바꿀 수 있음)

| 과목 유형 | 기본 사운드 | 이유 |
|---|---|---|
| 암기형 | 🎷 재즈 무드 | 가사가 없어 외우는 작업과 부딪히지 않습니다 |
| 계산형 | 🎧 로파이 비트 | 일정한 리듬이 문제 푸는 속도를 잡아 줍니다 |
| 독해형 | 🌧️ 빗소리 | 가사도 박자도 글 읽기를 방해합니다 |
| 창의·서술형 | ☕ 카페 소음 | 적당한 웅성거림이 발상에 도움이 됩니다 |
| 혼합형 | 🟤 브라운노이즈 | 주변 말소리를 가장 잘 가려 줍니다 |

#### 상태에 따른 자동 조정

지금 설정이 오늘 상태에 맞지 않을 때만 바꿔 주고, 이미 맞는 소리를 골라 두었다면 설정을 그대로 존중합니다.

1. **독해형인데 가사·박자가 있으면** → 빗소리
2. **암기형인데 가사가 있으면** → 재즈 무드
3. **스트레스 7 이상인데 자극적인 소리면** → 파도
4. **피로 7 이상인데 단조로운 소리면** → 로파이 비트 (독해형은 제외)
5. **집중력 52점 이하인데 음악을 틀었으면** → 브라운노이즈
6. **밤 10시 이후인데 자극적인 소리면** → 모닥불

바뀔 때마다 왜 바꿨는지 한 줄로 설명합니다. 자동 조정이 싫으면 체크박스로 끌 수 있습니다.

#### 🎵 내 음악 (K-pop 등) 등록

> **좋아하는 노래는 본인 음원 파일을 등록해서 씁니다.**
> 상업 음원은 앱에 넣거나 스트리밍할 수 없어서(저작권), 대신 기기에 있는 파일을 고르는 방식입니다.

`＋ 음악 파일 고르기` 로 mp3·m4a·wav 를 등록하면 과목별 설정 목록에 나타납니다.
계산형에 지정하면 계산 문제를 풀 때 그 곡이 재생됩니다. 여러 곡을 넣으면 순서대로 이어서 재생됩니다.

- 파일은 **IndexedDB 에 이 브라우저 안에만** 저장되며 어디로도 전송되지 않습니다.
- 한 파일 25MB 이하, 오디오 파일만 받습니다.
- 내가 등록한 곡은 가사가 있다고 보고, 독해형·암기형에 지정하면 ⚠ 경고와 함께 자동으로 다른 소리로 바뀝니다.
- 곡을 삭제하면 그 곡을 쓰던 과목 설정은 기본값으로 자동 복구됩니다.

### ★ 내 성장 — 초·중학생 전용 성장 모드

학교급을 **초등학교 또는 중학교**로 선택하면 자동으로 켜집니다. 고등학교 이상은 기존 화면 그대로입니다.

| 요소 | 내용 |
|---|---|
| **경험치 & 레벨** | 순공 1분 = 1 XP. 미션 완료 +30 XP, 배지 획득 +50 XP. 레벨업에 필요한 XP는 레벨마다 60씩 늘어납니다. |
| **캐릭터 성장** | 🥚 알 뇌 → 🐣 아기 뇌(Lv.3) → 🧠 튼튼 뇌(Lv.6) → ⚡ 번쩍 뇌(Lv.10) → 🌟 반짝 뇌(Lv.15) → 🚀 우주 뇌(Lv.20) |
| **오늘의 미션** | 9개 후보 중 매일 3개가 뽑힙니다. 날짜를 씨앗으로 뽑기 때문에 하루 안에서는 바뀌지 않습니다. |
| **배지 16종** | 첫걸음 · 25분 클리어 · 3시간 챔피언 · 3일 연속 · 일주일 개근 · 아침형 뇌 · 꿀잠 요정 · 물 마시기 왕 · 우리 반 1등 등 |

| **쉬운 말 설명** | 학습 준비도 설명과 학습법 문구가 초·중학생용 쉬운 표현으로 바뀝니다. |

미션과 배지는 **실제 기록에서만** 판정합니다. 물 6컵 배지는 물 입력이 6컵 이상일 때, 첫걸음 배지는 집중 블록을
정말 완주했을 때만 주어집니다. 그냥 주는 보상은 없습니다.

> 예: 학습법 문구가 이렇게 바뀝니다.
> **(고등학교 이상)** "다단계 계산이 필요한 고난도 문항을 지금 배치하는 게 가장 효율적입니다."
> **(초·중학교)** "시계를 맞춰 놓고 문제를 쭉 풀어 보세요. 어려운 문제일수록 지금 푸는 게 좋아요."

### 🎨 프로필 캐릭터 꾸미기

**설정 → 내 프로필 → 캐릭터 꾸미기** 에서 들어갑니다. 고른 모습은 **그룹 랭킹**과 상단 프로필에 그대로 나옵니다.

| 항목 | 내용 |
|---|---|
| **캐릭터 8종** | 남학생 3 · 여학생 5. 머리 모양과 옷이 다른 8명 중에서 고릅니다. |
| **테두리 5색** | 기본 · 라벤더(10시간) · 스카이(30시간) · 로즈(80시간) · 오로라(200시간) |

테두리는 **지금까지 쌓인 순공 시간**으로 하나씩 열립니다. 등급을 매기거나 남과 비교하지 않고,
공부한 시간만큼 예쁜 색을 하나씩 더 쓸 수 있게 하는 장치입니다.
배지와 같은 기준으로 **타이머로 실제 측정된 시간에서만** 판정하며, 한 번 열린 색은 사라지지 않습니다.

캐릭터 그림은 `src/avatar-sheet.png` 한 장에 모여 있습니다(4열 × 2행, 셀 200px).
각 칸은 **원본 그림 그대로**입니다 — 옷을 갈아입히거나 색을 바꾸지 않습니다.
조합해서 만들지 않으므로 8명 모두 그려진 완성도 그대로 나옵니다.

### 05. 그룹 랭킹

같은 반 안에서 **오늘 / 이번 주** 순공 시간으로 등수가 매겨집니다.
🥇🥈🥉 메달, 진행 막대와 연속 학습일이 함께 표시됩니다. 학습 준비도 참고값은 개인 계획에만 쓰며 경쟁 순위의 기준으로 사용하지 않습니다.

**학교 리그**와 **학급 대항전**을 모두 켜면 같은 학교·학교급·학년·반 친구들이 자동으로 동기화됩니다.
닉네임은 순위표에 그대로 표시되므로 실명은 권하지 않습니다. 같은 반에서 5명 이상 참여해야 다른 학생에게
개별 순위가 공개되며, `내 랭킹 숨기기`를 켜면 반 합계에는 포함되지만 내 줄은 다른 학생에게 보이지 않습니다.

예전 공유 코드로 저장한 그룹 기록은 서버 연결이 없을 때의 로컬 호환을 위해 읽을 수 있지만,
현재 화면에서는 공유 코드를 새로 등록하지 않습니다.

### 🏆 반·학교 리그

- 기본 화면은 같은 반이 한 팀이 되는 **반 대항**입니다.
- **학교 대항** 탭에서는 학교별 주간 순공 시간 합계를 비교합니다.
- 한 사람이 하루에 리그에 반영할 수 있는 순공 시간은 최대 5시간입니다.
- 매주 월요일에 승급·강등을 계산하며, 반 대항은 5개 반 이상 모여야 시작합니다.
- 전송을 끄면 이 기기의 기록은 더 이상 올라가지 않고 로컬 데이터만 표시합니다.

Supabase 테이블·함수·관리자 계정 설정은 [`supabase/README.md`](supabase/README.md)를 따릅니다.

### 수정하는 법

1. `src/` 안의 파일을 고칩니다.
2. PowerShell 에서 아래를 실행하면 `index.html` 이 다시 만들어집니다.

```bash
powershell -ExecutionPolicy Bypass -File build.ps1
```

`index.html` 은 CSS·JS가 전부 인라인된 **단일 자체 완결 파일**이라 USB나 메일로 옮겨도 그대로 실행됩니다.
`src/js/` 에 파일을 추가했다면 `build.ps1` 의 `$jsFiles` 와 `src/index.html` 의 script 태그를 함께 고쳐야 합니다
(두 목록이 어긋나면 빌드가 에러로 알려 줍니다).

### 점수 모델을 조정하려면

- **가중치**: `src/js/engine.js` 의 `CAPACITIES[].weights` (각 참고값의 합은 반드시 1.0)
- **요인 곡선**: `src/js/engine.js` 의 `FACTORS[].value` — 모든 곡선에서 **0.5가 중립**입니다.
  0.5 지점이 "그 지표의 무난한 수준"에 오도록 맞춰야 감점·가점이 제대로 찍힙니다.
- **시간대 곡선**: `src/js/engine.js` 의 `CIRC` (보정 폭은 `CIRC_FLOOR` 로 최대 25%)
- **배분 공식**: `src/js/planner.js` 의 `plan()` 안 `priority` 계산식
- **학습법 문구**: `src/js/planner.js` 의 `METHODS`
- **주간 총평 규칙**: `src/js/report.js` 의 `summarize()`
- **배지·미션·레벨 곡선**: `src/js/kids.js` 의 `BADGES`, `MISSION_POOL`, `needFor()`, `CHARS`
- **테두리 색·해금 시간**: `src/js/avatar.js` 의 `BORDERS` (링 모양은 `styles.css` 의 `.av-b1`~`.av-b5`)
- **캐릭터 그림**: `tools/avatar-source.png` 를 고친 뒤 아래를 실행하면 스프라이트가 다시 만들어집니다.
  잘라 내는 위치는 스크립트 안 `$CHARS`(가운데 x·좌우 폭)와 `$CHAR_TOP` 에 있습니다.

  ```bash
  powershell -ExecutionPolicy Bypass -File tools/slice-avatar.ps1
  ```
- **쉬운 말 문구**: `src/js/engine.js` 의 `kidsDesc`, `src/js/planner.js` 의 `kidsBody`
- **사운드 기본 매핑·자동 조정 규칙**: `src/js/sound.js` 의 `DEFAULT_MAP`, `recommend()`
- **새 사운드 추가**: `src/js/sound.js` 의 `TRACKS` 에 항목을 넣고 `BUILDERS` 에 생성 함수를 등록
- **나이스 API**: `src/js/neis.js` — 인증키는 소스에 두지 않습니다(`DEFAULT_KEY` 는 빈 문자열).
  다른 서비스(학사일정 `SchoolSchedule`, 시간표 등)를 붙이려면 `call(path, params, service)` 를 그대로 쓰면 됩니다.

## 참고

이 앱의 점수는 수면·스트레스·영양·일주기 리듬에 관한 공개된 인지과학 연구 경향

개인차를 반영하지 않은 일반화된 추정치이며, 의학적 진단이나 치료 목적으로 사용할 수 없습니다.
