# Mindora 청여고

청주여자고등학교 학생을 위한 학습 루틴 앱입니다. 자기보고 입력을 바탕으로 학습 준비도 참고값과 계획을 보여 주고, 타이머·학습 기록·학교 급식·시간표를 제공합니다. 준비도는 의학적 진단이나 능력 측정이 아닙니다.

## 화면과 데이터

| 경로 | 내용 |
|---|---|
| `/` | 앱과 PWA 자원 |
| `/landing/` | 소개 |
| `/privacy/` | 개인정보처리방침 |

프로필 학교와 나이스 학교 코드는 청주여자고등학교로 고정합니다. 학년·반은 학생이 입력하며 재학 여부를 인증하지 않습니다. 청여고 반 대항전은 별도 동의를 받은 기록만 표시합니다. 개인의 상태 입력과 학습 기록은 기본적으로 브라우저에 저장됩니다. 리그·관리자 공개·복구 코드 백업은 각각 선택 기능입니다. 복구 코드 백업은 브라우저에서 암호화한 뒤 서버로 보냅니다. 정확한 전송 항목과 삭제 방법은 `/privacy/`를 참고하세요.

프로필 캐릭터는 동복 10종·하복 10종의 완성형 그림에서 고릅니다. 교복과 머리 모양을 따로 조합하는 기능은 없습니다.

과거 여러 학교를 대상으로 만들었던 코드와 저장 기록의 일부는 기존 사용자 데이터 호환을 위해 남아 있습니다. 공개 프로필 화면과 반 대항전 화면은 청여고를 기준으로 표시하지만, 이 앱에 재학 인증이나 서버 차원의 청여고 전용 접근 제한이 구현된 것은 아닙니다.

## 개발과 배포

- 원본: `src/index.html`, `src/css/`, `src/js/`, `src/`의 정적 자원
- 배포 파일: 루트의 `index.html`, `css/`, `js/`, PWA 자원
- 소개·개인정보 안내: `landing/index.html`, `privacy/index.html`
- 빌드: PowerShell에서 `./build.ps1` 실행. `src/` 변경 후 루트의 생성물도 함께 커밋합니다.
- 정적 호스팅의 기본 경로는 `/`이고 소개 페이지는 `/landing/`입니다. 기존 설치형 앱과 북마크가 루트를 사용합니다.

프로필을 시험할 때는 별도의 브라우저 프로필을 사용하세요. 기존 브라우저 저장소를 비우면 실제 학습 기록이 지워집니다. 서버 기능의 스키마는 `supabase/`에 있으며, 배포 전에는 서비스의 실제 데이터베이스 설정과 도메인 연결을 별도로 확인해야 합니다.
